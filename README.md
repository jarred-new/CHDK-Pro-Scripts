# CHDK-Pro-Scripts
Scripts for your CHDK Canon Digicam...

# How to install these script to my camera?
1. Download the script you want to use at the script folder.
2. Copy the script to your SD card in the CHDK folder (usually named "SCRIPTS").
3. Insert the SD card into your camera and turn it on. Make sure CHDK is running.

# How to run the script?
1. Switch the camera to ALT mode (which is usually on the print button or the "FUNC" button, depending on your camera model).
2. Navigate to the "CHDK" menu and select "Scripts". Alternatively, you can also press the "ALT" button and then the "FUNC" button to access the script menu.
3. Select the script you want to run and press "OK".
